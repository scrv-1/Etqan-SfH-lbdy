# Etqan

صفحة عربية واحدة كبداية فقط، باستخدام HTML وCSS قياسيين. التنسيق داخل `index.html`؛ لا توجد مكتبات أو متطلبات تثبيت أو JavaScript أو خدمات خارجية.

## التشغيل

افتح `index.html` مباشرة في أي متصفح حديث، على الكمبيوتر أو الجوال. لا يلزم خادم أو اتصال بالإنترنت.

زر «ابدأ» عنصر مرئي بلا وظيفة أو وجهة في هذه المرحلة.

## النقل لاحقًا إلى GitHub

أنشئ مستودعًا جديدًا وارفع إليه الملفات الثلاثة فقط: `index.html` و`README.md` و`replit.md`. لا تحتاج إلى ملفات القالب الأخرى الموجودة في بيئة التطوير. يمكن فتح الصفحة محليًا، أو نشرها لاحقًا عبر GitHub Pages دون بناء أو تثبيت اعتماديات.

قواعد النطاق للمحادثات القادمة موثقة في `replit.md`.
